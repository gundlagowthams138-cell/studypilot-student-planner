# StudyPilot — Student Productivity Dashboard

StudyPilot is a responsive student planner built with HTML, CSS, and vanilla JavaScript. It helps students organize assignments, set deadlines, track completion, and build consistent study habits.

## Features

- Add tasks with a subject, due date, and priority
- Mark tasks as complete or incomplete
- Delete individual tasks
- Filter all tasks, tasks due today, and completed tasks
- View total tasks, completed tasks, due-today count, and completion percentage
- Automatically save tasks in browser `localStorage`
- Responsive layout for desktop, tablet, and mobile
- Reset to sample tasks for demonstration

## Tech stack

- HTML5
- CSS3 (responsive layout and media queries)
- JavaScript (DOM manipulation, events, array methods, localStorage)

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Add a task and refresh the page to verify that tasks are saved.

No build tools or package installation are required.
